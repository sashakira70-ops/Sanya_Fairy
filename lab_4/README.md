## Опис завдання
Програма реалізує візуалізацію функції гармоніки з накладеним шумом. Присутній інтерактивний інтерфейс (слайдери, чекбокс, кнопка скидання) для налаштування амплітуди, частоти, фази гармоніки та параметрів шуму (середнє значення, дисперсія). Зашумлений сигнал фільтрується за допомогою IIR фільтра низьких частот `scipy.signal.iirfilter`, користувач має можливість налаштовувати частоту зрізу в реальному часі.
