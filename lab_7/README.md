## Опис завдання
Метою роботи є реалізація багатопотокового застосунку для детекції облич на відео в реальному часі. Використано архітектуру розділення потоків (UI-потік та Worker-потік) для запобігання блокуванню інтерфейсу під час роботи нейромережі.

## Архітектура рішення
Програма побудована на взаємодії двох потоків:

1. **Main Thread (UI):** - Захоплення кадрів з веб-камери (`cv::VideoCapture`).
   - Віддзеркалення кадру (`cv::flip`) та візуалізація результатів.
   - Відображення FPS та статусу детекції.
   - Не очікує завершення інференсу нейромережі, забезпечуючи плавність картинки.

2. **Worker Thread (FaceDetector):**
   - Фонова обробка кадрів через нейронну мережу ResNet-10 (Caffe).
   - Використання `std::mutex` для безпечного обміну даними (передача кадру та отримання координат облич).
   - Штучна затримка (`std::this_thread::sleep_for`) додана для демонстрації незалежності потоків.
