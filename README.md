## Опис завдання
Ознайомлення з бібліотекою Pandas, завантаження та очистка даних (Data Cleaning). 
- **Частина 1:** Завантаження даних індексу VHI з NOAA, їх очистка та зміна індексів областей України. Написання функцій для формування вибірок.
- **Частина 2:** Аналіз набору даних Individual Household Electric Power Consumption. Формування вибірок, нормування, стандартизація, кореляційний аналіз та One Hot Encoding з оцінкою часу виконання процедур (timeit).

## Інструкція налаштування і запуску
1. Створіть віртуальне середовище:
   `python -m venv venv`
2. Активуйте віртуальне середовище:
   - Windows: `venv\Scripts\activate`
   - Linux/Mac: `source venv/bin/activate`
3. Встановіть залежності:
   `pip install -r requirements.txt`
4. Запустіть Jupyter Notebook та відкрийте файли `part1.ipynb` або `part2.ipynb`:
   `jupyter notebook`
