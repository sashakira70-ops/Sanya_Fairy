## Керування та режими обробки

**Клавіатура (фільтри):**
- `0` - Оригінальне зображення (без фільтрів)
- `1` - Чорно-білий фільтр (Grayscale)
- `2` - Виділення контурів (Canny)
- `3` - Негатив (Інверсія кольорів)
- `4` - Фільтр Собеля
- `5` - Бінаризація (Threshold)
- `6` - Глітч-ефект (Зсув кольорових каналів)
- `8` - **Гаусове розмиття (Індивідуальний фільтр для Варіанту 8)**
- `q` - Завершення роботи програми

**Інтерактивні елементи:**
- **Повзунок "Brightness":** Регулювання яскравості зображення у реальному часі.
- **Миша:** Клік лівою кнопкою миші по вікну виводить координати (X, Y) у термінал.
